# Оно тебе надо

Учебная проектная работа Яндекс Практикума: страница аукциона.

Репозиторий: https://github.com/SPOKpupok/ono-tebe-nado-ad.git

Для просмотра откройте `index.html` в браузере.

Страница свёрстана на HTML и CSS: семантическая разметка, Grid и Flexbox, локальные шрифты Raleway. Ширина макета — 1100 пикселей.

Кнопка «Сделать ставку» и ссылки на лоты — элементы учебного макета; логика аукциона заданием не предусмотрена.
